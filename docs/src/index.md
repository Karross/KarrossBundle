# Karross

A Symfony bundle that gives you an instant admin interface for your Doctrine
entities - out of the box, and fully customizable.

- [Quickstart](quickstart.md) - install it and get a working admin in minutes
- [Presentation](presentation.md) - what Karross does
- [Customization](customization/index.md) - adapt routes, value formatting, templates, translations and output
- [Roadmap](roadmap.md) - what's planned
- [How to contribute](contribute.md) - help the project
